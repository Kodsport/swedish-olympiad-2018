\problemname{Stulen sträng}
You and your accomplice Acsel have stolen a string of length $n$ from your enemy Waxel. You now want to split the string so that you get
exactly the same number of each letter each. However, splitting a string is expensive, so your task is to find the minimum number of splits required for you to divide the loot equally.

For example, if the string was ``$\textit{acabbc}$'', you could split the string into
``$\textit{a}+\textit{cab}+\textit{bc}$''. Then you can take the first and last piece while Acsel takes the middle piece. This required two splits,
and that is also the minimum in this case.

\section*{Input}
The first and only line contains a string of length $n$, consisting of the letters \texttt{'a'}, \texttt{'b'}, \texttt{...}, \texttt{'a'} $+(k-1)$. For bounds on $n$ and $k$, see below.

\section*{Output}
Print a single integer, the minimum number of splits required. If it is not possible to divide the loot equally, print ``$-1$''.

\section*{Scoring}
Your solution will be tested on a set of test groups.
To earn points for a group, you must pass all test cases in that group.
