\problemname{Subway Seats}

Baltic Olympiad in Informatics --- the programming competition for countries in
the Baltic Sea region --- will be held in Stockholm this spring, and
the participants will ride the subway between the hostel and the competition arena.

On the subway trains there are seat groups of four seats each. Now
a number of groups of participants arrive and want to sit down. Each group
has size 1, 2, 3, or 4. Ideally, all the people in a group
would like to sit in the same four-seat group, i.e.\ not have to split up. How many four-seat groups are required for this to be possible?

\section*{Input}

The input consists of one line with four integers $a_1, a_2, a_3, a_4$ --- the number of groups of each size. All numbers are between $0$ and $100$.

\section*{Output}

Output a single number: the minimum number of four-seat groups needed so that
the people can sit down with everyone within each group sitting together.

\section*{Scoring}
For test cases worth $20$ points, there are no groups of size 1.\\
For test cases worth $20$ points, there are no groups of size 2.\\
For test cases worth $20$ points, there are no groups of size 3.\\
For test cases worth $40$ points, no special constraints apply.
